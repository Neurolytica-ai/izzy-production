# Progress Report — Izzy Yogev Production System

Date: 2026-07-29

## Headline

**The system is deployed and live in production over HTTPS**, and the interface
now has a **one-click Hebrew ⇄ English toggle with right-to-left support**.

Live URL: **https://srv1859122.hstgr.cloud**

## Production deployment (done + verified)

Ran the full deploy runbook (`docs/DEPLOY.md`) over SSH against the client's
Hostinger server:

- **Server hardened** as requested: a non-root `neurolytica` sudo user was
  created, root SSH login was disabled, and both the root and the shared
  install password were rotated off the plaintext one from the work plan.
- **Dockerized** (the preferred approach): the app, an nginx reverse proxy, and
  a one-shot that publishes the built front end all run under Docker Compose.
- **HTTPS** with a valid Let's Encrypt certificate, an automatic HTTP→HTTPS
  redirect, and a daily auto-renewal job so the certificate never lapses.
- **Database** stays on Supabase (managed Postgres), reached over the IPv4
  connection pooler; the app confirmed it can read and write to it.
- **Survives a reboot unattended** — verified by rebooting the server and
  confirming the site came back up on its own.

Click-tested live: signing in, editing master data (added an employee), and the
hours-entry grid (a row saved and persisted across a reload).

## Hebrew / RTL language toggle (done + deployed)

Per the request for an in-app language switch so the Hebrew wording can be
refined against real user feedback:

- A **🌐 language button in the header** swaps the entire interface between
  Hebrew and English and flips the layout to right-to-left. The choice is
  remembered per browser.
- The app now **defaults to Hebrew (RTL)** — the end users' language — with
  English one click away for anyone who prefers it.
- The Hebrew wording is taken from the **original prototype's own labels**
  wherever one existed, so users see the terms they already know. Refining any
  Hebrew string later is a one-line change.
- Every screen and shared control was moved onto the translation system; the
  layout was corrected for right-to-left throughout (including the grid's
  autocomplete dropdown).

Verified live: the site loads in Hebrew/RTL and the toggle switches to English
and back.
